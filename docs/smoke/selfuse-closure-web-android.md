# 自用闭环手顺（Web + Android 双端）

> 对应计划「自用最低验收」。两端均常用时建议：**一端创建、另一端拉同步验证**。

## 前置

1. 服务端：`cd server && go run ./cmd/eve`（或 Docker compose），记下 URL。
2. Web：`cd web && npm run dev` → 浏览器登录并解锁。
3. Android：模拟器 `10.0.2.2:8787` 或真机局域网 IP；登录并解锁。

## A. 财务（约 10 分钟）

| 步骤 | Web | Android |
|------|-----|---------|
| 日常记账 | `/finance` → 记一笔支出 | 财务 Tab → 新建流水 |
| v2 条目 | 新建「订阅」或「保单」一条 | 同上 |
| 同步 | 锁定再解锁或等待 vault.sync | 下拉同步 / 等待 Worker |
| 对端可见 | 刷新财务列表 | 打开财务列表核对 |

期望：另一端出现同 id 条目；卡账单日/还款日提醒链无崩溃（不必等真机闹钟）。

## B. 物品（约 10 分钟）

| 步骤 | Web | Android |
|------|-----|---------|
| 新建 | 侧栏「物品」→ 新建（类别+保修天数） | Vault →「物品」→ 新建 |
| 同步 | 触发同步 | CollectorWorker / 手动同步 |
| 编辑 | Web 改备注 | Android 改标签 |
| 二维码 | 详情页展示 QR（payload=uuid） | 详情 QR / 扫码页 |

期望：LWW 后两端最终一致；通知不含物品名称。
